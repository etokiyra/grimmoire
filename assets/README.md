# Image assets

Every PNG here is **original artwork generated by this repository**. There is no
third-party imagery, so there are no usage rights to track and no external
credits to maintain.

## Files

| File | Used for | Size |
| --- | --- | --- |
| `chapel.png` | The establishing plate for the Ruined Chapel | 600 × 200 |
| `cellar.png` | The establishing plate for the Sunken Cellar | 600 × 200 |
| `portrait.png` | The hooded figure, in the dialogue overlay | 320 × 300 |

They are deliberately few. The world itself is drawn with character cells; images
are reserved for places where a picture materially helps - an arrival card when
you enter an area, and a portrait while someone is talking.

## Regenerating

```sh
tools/generate-assets.sh
```

Requires ImageMagick 7 (`magick`). The output is deterministic, so regenerating
produces byte-identical files and a clean `git status`.

## How they are built

Each plate is three layers: a gradient sky, a silhouette drawn on a transparent
canvas with the openings punched out using an even-odd path, and a foreground.
The plates are then quantised to 128 colours and stripped, which keeps the
repository small and the transmission to the terminal quick.

## Palette

The assets are tuned to the terminal theme in `src/ui/theme.rs`: a near-black
violet base (`#05040a`…`#170f2e`), warm stone and ember highlights
(`#6b4520`…`#f2c982`), and a cold cyan for the cellar (`#5fc6d0`). Nothing here
is brighter than the theme's `text` token, so the artwork never competes with
readable text.
